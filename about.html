About QuickNotes

QuickNotes is a lightweight note-taking app for jotting down ideas, tasks and reminders without any clutter. It helps you capture a thought in seconds and find it again just as quickly.

How to use QuickNotes

  1. Open QuickNotes and click "New note".
  2. Type a title and write your note.
  3. Save the note so it appears in your list.
  4. Use the search box to find a note later.

Features

  • Create, edit and delete notes
  • Instant search across all notes
  • Simple, distraction-free interface
  • Keyboard shortcuts for fast writing

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search your notes
